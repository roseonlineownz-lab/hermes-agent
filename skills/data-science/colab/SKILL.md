# Google Colab — Generate & Hand-off Notebooks

Colab has **no public API**: there is no programmatic way to start a notebook session, attach a GPU, or read cell output. What an agent *can* do is generate a runnable `.ipynb` file and hand the user a URL that opens it in Colab. That covers 90% of the "run this on free GPU" use case.

## Free runtime tiers (subject to change)

| Tier | GPU | RAM | Disk | Session | Cost |
|---|---|---|---|---|---|
| Free | T4 (sometimes K80, sometimes none — unlucky day) | 12 GB | 80 GB | ~12 h | $0 |
| Pro | T4 / L4 / sometimes A100 | up to 25 GB | larger | 24 h | $9.99/mo |
| Pro+ | A100 / V100 mostly | up to 52 GB | larger | 24 h, background exec | $49.99/mo |

Run `!nvidia-smi` as the first cell of a notebook to confirm what you actually got.

## Generate a notebook from agent code

```python
# build a minimal nbformat-compatible dict — no need for the nbformat library
import json, pathlib

def make_nb(setup: str, body: str, out: pathlib.Path) -> pathlib.Path:
    cells = [
        {"cell_type": "markdown", "metadata": {},
         "source": ["# Auto-generated by Hermes\n",
                    "Open with: `Runtime → Change runtime type → GPU`, then run all cells."]},
        {"cell_type": "code", "metadata": {}, "execution_count": None, "outputs": [],
         "source": setup.splitlines(keepends=True)},
        {"cell_type": "code", "metadata": {}, "execution_count": None, "outputs": [],
         "source": body.splitlines(keepends=True)},
    ]
    nb = {"nbformat": 4, "nbformat_minor": 5,
          "metadata": {"kernelspec": {"name": "python3", "display_name": "Python 3"},
                       "language_info": {"name": "python"},
                       "accelerator": "GPU", "colab": {"name": out.stem, "provenance": []}},
          "cells": cells}
    out.write_text(json.dumps(nb, indent=2), encoding="utf-8")
    return out

setup = """!pip install -q transformers accelerate
!nvidia-smi
"""

body = """from transformers import pipeline
pipe = pipeline('text-generation', model='gpt2', device=0)
print(pipe('Once upon a time,', max_new_tokens=50)[0]['generated_text'])
"""

make_nb(setup, body, pathlib.Path("/tmp/hermes-demo.ipynb"))
```

## Hand-off URLs

| Source of the notebook | URL to share |
|---|---|
| GitHub repo `org/repo`, path `notebooks/x.ipynb`, branch `main` | `https://colab.research.google.com/github/org/repo/blob/main/notebooks/x.ipynb` |
| Gist `abcdef`, file `x.ipynb` | `https://colab.research.google.com/gist/<user>/abcdef/x.ipynb` |
| Google Drive file id `1xyz` | `https://colab.research.google.com/drive/1xyz` |
| Local file (user uploads manually) | `https://colab.research.google.com/` then File → Upload |

Most agent flows: push the generated `.ipynb` to a github gist or repo, then return the github-Colab URL.

## Workflow patterns

- **GPU-hungry inference:** generate a notebook that pulls model weights from HF and runs against an attached dataset; share the URL so the user clicks **Runtime → Run all**.
- **Validation harness:** include test cells that error-out loudly so the user sees if the run failed (markdown summary at the bottom).
- **Mount Drive for results:**
  ```python
  from google.colab import drive
  drive.mount('/content/drive')
  ```
  This prompts the user once; subsequent runs reuse the cached creds.

## Gotchas

- **No background execution on free tier.** Closing the browser tab kills the kernel within ~90 minutes. Use `nohup`-style shell tricks inside the notebook or upgrade to Pro+.
- The free GPU lottery is real — sometimes Colab assigns no GPU at all. Detect with `import torch; torch.cuda.is_available()` and fall back gracefully.
- Don't include API keys in the notebook source. Either prompt the user to paste them (`from getpass import getpass`) or load from Google Drive (`/content/drive/MyDrive/secrets.env`).
- Notebooks larger than ~5 MB load slowly in the Colab UI. Trim cell outputs before sharing.
